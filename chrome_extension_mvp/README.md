# Chrome 扩展 MVP

这是一个最小可用的 Chrome 扩展骨架，用于在用户自己的浏览器页面里提取 YouTube / Bilibili 的可见字幕文本。

## MVP 目标

- 在用户自己的浏览器上下文中提取页面可见字幕
- 把字幕复制到剪贴板
- 打开主站的 `✍️ 粘贴字幕` 页签，由主站完成 AI 总结

## 当前能力

- YouTube：尝试读取 transcript 面板中的可见字幕节点
- Bilibili：尝试读取页面中的可见字幕节点
- Popup 中支持：
  - 提取字幕
  - 复制字幕
  - 打开主站

## 当前限制

- 这是 MVP，不保证所有页面结构都能提取成功
- 当前只读取“页面已可见”的字幕文本
- 如果视频页面没有打开 transcript / 字幕面板，可能提不到内容
- 当前不直接调用主站接口上传文本，而是先复制到剪贴板，手动粘贴到主站

## 安装方式

1. 打开 Chrome 扩展管理页面：`chrome://extensions/`
2. 打开“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录 `chrome_extension_mvp`

## 建议使用流程

1. 打开 YouTube / Bilibili 视频页面
2. 尽量先展开 transcript / 字幕面板
3. 点击扩展图标
4. 点击“提取字幕”
5. 点击“复制文本”
6. 打开主站，切到 `✍️ 粘贴字幕` 页签
7. 粘贴并生成总结
