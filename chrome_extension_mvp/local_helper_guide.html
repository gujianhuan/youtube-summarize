本地转写助手引导

当前视频没有可直接提取的公开文本时，才需要使用本地转写助手做兜底转写。

什么时候需要它

  • 视频没有公开字幕，也没有可提取的 transcript。
  • 扩展已经明确提示“建议使用本地转写助手”。
  • 你需要先本地转写，再回主站继续总结。

你现在要做什么

  1. 复制当前视频链接。
  2. 打开本地转写助手。
  3. 把视频链接粘贴进去。
  4. 点击开始转写。
  5. 转写完成后自动回到主站继续总结。

当前视频链接

如果这里没有链接，请回到视频页面后重新点击扩展里的“查看本地工具说明”。

版本选择建议

  • 在线安装版：首包更小，首次运行需要联网下载完整运行包。
  • 便携瘦身版：包更大，但适合离线分发和测试。
  • 开发命令行版：只适合开发者调试，不适合普通用户。

注意

  • 如果扩展提示的是“提取失败”，不要急着装本地工具，先重试或手动展开 transcript 面板。
  • 本地工具只处理“确实没有可提取文本”的视频，不应该拿来掩盖扩展故障。
  • 如果视频需要登录验证，可能还需要读取浏览器 cookies。

补充说明

  • 在线安装版更适合直接发给朋友，首包更小，但第一次运行必须联网。
  • 便携瘦身版适合离线分发，但包体更大。
  • 如果你只是想继续总结，不需要手动复制 transcript，本地工具完成后会自动回到主站。
